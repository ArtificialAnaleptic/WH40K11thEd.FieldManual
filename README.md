# WH40K 11th Ed. Field Manual
A quick and easy to use page when learning to play WH40K 11th Ed. Download and run locally on your phone or PC. Or access via the github site. Step through each stage of your turn in 11th Ed. or access key words and universal stratagems quickly and easily.

If the page looks too small: **ensure your phone's browser is not requesting a "desktop version" of the site**.

Based off of the work by /u/Kaysette in this post: https://www.reddit.com/r/Warhammer40k/comments/1tv312v/11th_edition_cheat_sheet/

Built for mobile but should work on desktop too. I only have one phone to test on so please let me know if you encounter issues and **please list device model and resolution if you register an issue related to rendering the page.**

You can access the site directly from github here: https://artificialanaleptic.github.io/WH40K11thEd.FieldManual/

Or you can simply save the "[index.html](https://github.com/ArtificialAnaleptic/WH40K11thEd.FieldManual/blob/main/index.html)" to your phone or computer and then open it with your web-browser of choice. This will mean that it is usable even if your device is disconnected from the internet.
