# WH40K 11th Ed. Field Manual
A quick and easy to use page when learning to play WH40K 11th Ed. Download and run locally on your phone or PC. Or access via the github site. Step through each stage of your turn in 11th Ed. or access key words and universal stratagems quickly and easily.

Based off of the work by /u/Kaysette in this post: https://www.reddit.com/r/Warhammer40k/comments/1tv312v/11th_edition_cheat_sheet/
